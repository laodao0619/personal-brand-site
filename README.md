# 高嘉隆个人品牌站

使用 Astro 构建的静态网站。运行 `pnpm install` 安装依赖，`pnpm dev` 启动本地预览，`pnpm build` 生成静态页面。

六个页面复用 Muse 导出稿的版式和插画。公开版 Markdown 存在 `src/content/`，包括跨境六专题、每日样例和修学归档摘录。跨境笔记保留可公开的原文段落、学习目标和已有溯源链接。为公开发布删除了内部数据和账号信息。修学摘录保留事实等级，两处缺少截图的条目标记为「豆包自述已核实，截图待补」。

服务页根据案例底稿保留可公开的定性结论。提交前检查 Markdown、静态资源和构建产物是否含内部资料。联系方式由站主补填。

发布流程仅创建功能分支和 PR，通过 Vercel Preview 验收。
