# 深海下潜：内容与验收

## 实现范围

- `/deep-sea/`：中文静态页面，0–10,935 米，5 个海洋分层。
- 19 个生物节点、4 个途中历史/尺度节点，终点附 Trieste 载人下潜故事。
- 原创几何 SVG；未加载 Neal.fun 素材、图片、文本或第三方嵌入。
- 实时米/英尺计数、关键节点提示、分层跳转、返回海面。
- 内容由服务器静态输出，关闭 JavaScript 仍可阅读。实时仪表仅在脚本初始化后显示。
- 无音频或自动播放。`prefers-reduced-motion: reduce` 停止漂浮和滚动动画。
- 首页只新增入口；原有九页的文案、链接及印记逻辑保持原样。

## 深度与滚动

每个真实深度节点都有 `data-depth`。计数器取视口从顶部向下 30% 处作为观测线，在相邻节点的实际页面位置间线性插值。资料展开、窗口改变会触发重新测量。锚点同样落在 30% 处；用一像素容差处理浏览器滚动舍入。

这不是像素与米一一对应的比例图。浅层为阅读留出更长空间，深层保留大段空水。页面入口已明确说明。来源展开会改变页面长度，但不会改变节点代表的深度。

英尺换算采用 `米 / 0.3048`，显示四舍五入整数。终点限定 10,935 米，不随页面末尾参考资料继续增长。

本版暂未纳入皱鳃鲨、蜘蛛蟹、长尾鲨、盲鳗和名称含糊的“巨型章鱼”。任务单允许删去不确定条目；这些类群需要更明确的物种与适配来源，不沿用初稿的深度分组。新增生物应提供相应物种的可靠深度资料，而不是为了填补空白。

在构建产物上使用 Chrome / Playwright 检查 320×900、390×900、1280×900：
